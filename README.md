
# PSP MIXED ROBOT - Line Follower & Mission Control (POP7)
### Use for competitive(silapahattakum 70-71)

โปรเจกต์ควบคุมหุ่นยนต์เดินตามเส้นและทำภารกิจโดยใช้บอร์ด **POP7** พัฒนาด้วยภาษา C++ (Arduino IDE) โดยมีระบบการทำงานแบ่งตามทางเลือก (State) และการตรวจจับวัตถุ/เส้น ด้วยเซนเซอร์หลายจุด

## 📋 ข้อมูลการเชื่อมต่อพอร์ต (Pin Mapping)

| อุปกรณ์ | พอร์ต (Pin) | หน้าที่ |
| :--- | :--- | :--- |
| **เซนเซอร์เส้น (ซ้ายนอก)** | 29 | ตรวจจับเส้นสีดำด้านซ้ายสุด |
| **เซนเซอร์เส้น (ซ้ายใน)** | 27 | ตรวจจับเส้นสีดำด้านซ้ายกลาง |
| **เซนเซอร์เส้น (ขวานใน)** | 28 | ตรวจจับเส้นสีดำด้านขวากลาง |
| **เซนเซอร์เส้น (ขวานอก)** | 26 | ตรวจจับเส้นสีดำด้านขวาสุด |
| **Distance Sensor** | 30 | วัดระยะทาง (Analog) เพื่อประคองทิศทาง |
| **Button / Switch** | 31 | รับสัญญาณการกด หรือตรวจจับการชน |
| **Back Sensor** | 25 | ตรวจสอบวัตถุด้านหลังเพื่อเริ่มทำงาน |
| **Servo 1, 2** | 1, 2 | ควบคุมแขนกล/กลไกคีบ |
| **Servo 3** | 3 | ควบคุมการโบกธง (Flag) |

## ⚙️ ฟังก์ชันหลักที่สำคัญ

### 1. ระบบนำทาง (Navigation)
* `cross_left()` / `cross_right()`: เดินตามเส้นจนเจอทางแยก (เส้นดำตัดกัน) แล้วทำการเลี้ยวซ้ายหรือขวา
* `cross_dot()`: วิ่งข้ามเส้นตัดเพื่อตรงไปต่อ
* `go_green1()`: วิ่งตามเส้นโดยใช้เซนเซอร์วัดระยะ (Ultrasonic/Analog) เพื่อรักษาระยะห่างและประคองตัว

### 2. ระบบภารกิจ (Mission Control)
* `Robot_start()`: รอสัญญาณจากเซนเซอร์หลังก่อนเริ่มออกตัว
* `Flag()`: สั่งการให้ Servo 3 โบกธงสลับไปมา
* `cross_longward()`: วิ่งทางตรงระยะยาวและรอรับคำสั่งจากปุ่มกดที่ Pin 31 เพื่อทำงานกับแขนกล (Servo 1, 2)
* `stop_()`: หยุดมอเตอร์และรอการกดปุ่มเพื่อเริ่มใหม่

## 🚀 ลำดับการทำงาน (States)

หุ่นยนต์รองรับ 2 สถานะการทำงาน ซึ่งเลือกได้จากการกดปุ่มก่อนเริ่ม:

### **State 1: Full Course (ทางเต็ม)**
1. เริ่มต้นออกตัว (`Robot_start`)
2. เลี้ยวซ้าย 2 ครั้ง และเลี้ยวขวา 1 ครั้ง
3. วิ่งโหมดประคองระยะ (`go_green1`)
4. เลี้ยวขวาเข้าจุดภารกิจ
5. ทำภารกิจแขนกลที่ทางยาว (`cross_longward`)
6. โบกธงจบงาน (`Flag`)

### **State 2: Short Path (ทางลัด)**
1. เริ่มต้นออกตัว (`Robot_start`)
2. เลี้ยวขวาเข้าจุดภารกิจทันที (`cross_rightbeforechop`)
3. ทำภารกิจแขนกลที่ทางยาว (`cross_longward`)
4. โบกธงจบงาน (`Flag`)

## 🛠 การใช้งาน
1. เปิดไฟล์ด้วย Arduino IDE ที่ติดตั้ง Library `<pop7.h>`
2. อัปโหลดโค้ดลงบอร์ด POP7
3. วางหุ่นยนต์บนสนาม และกดปุ่มที่พอร์ต 31 หากต้องการเปลี่ยนเข้าสู่ State 2
4. ให้เซนเซอร์หลังตรวจพบวัตถุ (หรือเอามือบังแล้วปล่อย) เพื่อเริ่มการทำงาน

---
**หมายเหตุ:** ความเร็วหลักถูกตั้งไว้ที่ `sp = 90` สามารถปรับจูนได้ที่บรรทัดแรกของโค้ด
